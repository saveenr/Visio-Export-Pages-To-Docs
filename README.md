# Visio-Export-Pages-To-Docs

> **Status:** *paused*. CY27 docs cleanup tracked in [#5](https://github.com/saveenr/Visio-Export-Pages-To-Docs/issues/5).
>
> Command-line tool that splits a multi-page Visio document into one document per page. Requires Visio 2007 or above.
>
> Part of the [VisioAutomation portfolio](https://github.com/saveenr/VisioAutomation/blob/master/docs/RELATED-REPOS.md).

## Summary
Command line tool that lets you take a single doc with many pages and export it to multiple docs - each one with a single page

* The original doc is not modified
* Will not overwrite existing files
* Requires Visio 2007 and above
* Centers and Zooms the page before the export

## Download

Get it here: https://github.com/saveenr/Visio-Export-Pages-To-Docs/releases

## Usage

    VisioExportPagesToDocs.exe <input.vsd>
